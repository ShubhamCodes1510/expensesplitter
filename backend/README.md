# Expense Splitter Application

## 🚀 Overview
Group expense management and settlement system for friends, roommates, and travel groups.

## 📋 Features
- User Management
- Expense Tracking & Splitting
- Recurring Bills
- Receipt Upload
- Settlement Calculation
- JWT Authentication

## 🛠️ Tech Stack
- Java 17
- Spring Boot 3.2.1
- MySQL
- Maven
- JWT Authentication
